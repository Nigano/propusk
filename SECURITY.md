# Политика безопасности

Propusk — учебный проект (выпускная квалификационная работа). Не используйте его для защиты реальной инфраструктуры: сертификация не проводится, ограничения описаны в разделе «Ограничения» файла README.

## Как сообщить об уязвимости

Не создавайте публичный issue. Откройте вкладку Security → Report a vulnerability и опишите, что затронуто, как воспроизвести проблему и к чему она приводит. Ответ придёт в течение 7 дней.
