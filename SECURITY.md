# Политика безопасности

Propusk — учебный проект (выпускная квалификационная работа). До выхода версии 1.0 не используйте его для защиты реальной инфраструктуры.

## Как сообщить об уязвимости

Не создавайте публичный issue. Откройте вкладку Security → Report a vulnerability и опишите, что затронуто, как воспроизвести проблему и к чему она приводит. Ответ придёт в течение 7 дней.
